# 물마루 MULMARU — 제주 탑동 카페 랜딩페이지

제주더큰내일센터 1층 카페 창업용 랜딩페이지 시안입니다.

## 실행

`index.html`을 브라우저로 바로 열어도 되지만, 로컬 서버로 여는 것을 권장합니다.

```bash
python -m http.server 5173
```

열고 나서 <http://localhost:5173> 접속.

> 지도(Leaflet)와 웹폰트는 CDN을 쓰므로 인터넷 연결이 필요합니다.

## 구조

```
index.html              페이지 전체 마크업
assets/css/style.css    스타일 (감귤·현무암·바다 3색 팔레트)
assets/js/main.js       일몰 계산 · 메뉴 렌더링 · Leaflet 지도
```

## 개업 전 반드시 교체할 값

`assets/js/main.js` 상단 `CONFIG` 블록 한 곳만 고치면 됩니다.

| 항목 | 현재 값 | 비고 |
|---|---|---|
| `CONFIG.cafe.latlng` | `[33.5165, 126.5220]` | **대략 좌표.** 실제 건물 좌표로 교체 필요 |
| `CONFIG.cafe.address` | 제주시 탑동로 55 | 정확한 지번/도로명으로 교체 |
| `CONFIG.airport.latlng` | `[33.5064, 126.4936]` | 공항 국내선 도착층 앞 (근사) |
| `ROUTES[].path` | 근사 경로 좌표 배열 | 실제 도로 경로로 다듬을 것 |
| `ROUTES[].desc` | 버스 노선·요금 안내 | **예시 문구입니다.** 실제 노선번호·요금 확인 필요 |

전화번호(`064-000-0000`), 이메일, 가격은 `index.html`과 `MENU` 배열에 있습니다.

## 기능 메모

- **일몰 위젯** — NOAA 근사식으로 오늘 탑동의 일몰 시각을 브라우저에서 직접 계산합니다.
  실제 관측치와 3~5분 오차가 있습니다. 1분마다 갱신되며, 골든아워(일몰 30분 전)엔 배지 문구가 바뀝니다.
- **메뉴 탭** — `MENU` 배열의 `cat` 값(`signature` / `tea` / `coffee` / `dessert`)으로 필터링합니다.
  항목 추가는 배열에 객체 하나 넣으면 끝입니다.
- **경로 지도** — 이동 수단 버튼을 누르면 해당 폴리라인만 지도에 남고 자동으로 화면이 맞춰집니다.
  스크롤 휠 줌은 지도를 클릭해야 활성화됩니다(페이지 스크롤 방해 방지).
